# 2026-10-08 작업 기록

ESP32 / LVGL v7 Modbus 센서 모니터링 프로그램의 오늘 변경 내용과 검증 결과를 정리한 파일입니다.
이 기록은 오늘의 **최종 구현 상태**를 기준으로 정리했습니다. 현재 사용법은 [README.md](README.md)를 참고하세요.
현재 하드코딩 설정은 `main/modbus_src/lv_sensor_profiles.c`, 채널별 매핑은 `ModbusTable.csv`에서 확인할 수 있습니다.

## 1. 소스 구조 정리

- `components/lv_examples/lv_examples/src/lv_demo_widgets`에 섞여 있던 프로젝트용 Modbus·UI 소스를 `main/modbus_src`로 이동했습니다.
- `main/main.c`의 include와 `main/CMakeLists.txt`, `main/component.mk`의 소스·헤더 경로를 수정했습니다.
- 프로젝트 화면 코드의 `lv_examples` 헤더·데모 설정 의존성을 제거했습니다.
- 이후 홈 화면을 제거하면서 사용하지 않는 `lv_home_widgets.c/.h`와 관련 진입점·설정 헤더도 제거했습니다.

### 현재 주요 파일

| 파일 | 역할 |
|---|---|
| `main/modbus_src/lv_modbus.c` | Home / 센서별 그래프 탭 생성, 애플리케이션 테마 적용 |
| `main/modbus_src/lv_edpd_widgets.c` | Home 정보·보드레이트 선택, 센서 탭 전환, 시작·중지, 500ms 읽기 예약, 묶음 응답 매핑, 통합 그래프·현재값 표시 |
| `main/modbus_src/lv_modbus_connection.c` | UART, FC03 등 읽기 프레임, CRC, 응답 수신, 묶음 순차 실행 |
| `main/modbus_src/lv_sensor_profiles.c` | 센서별 Slave ID, Device Address, Scale/Offset, 단위, 센서 표시 범위 |
| `main/modbus_src/lv_app_font.c` | 영문 Montserrat 16 / 한글 Galmuri 글리프 선택 및 µ 기호 지원 |
| `ModbusTable.csv` | 34개 채널의 실제 사용 설정을 정리한 UTF-8 BOM CSV |

## 2. 최종 화면 및 조작

- **Home / LWTM / BTM / B-WACS / O-WACS / AVM**의 6개 탭으로 구성했습니다.
- Home 맨 위에는 보드레이트 제목을 두고, 그 아래 한 줄에 **왼쪽 속도 콤보박스 / 오른쪽 Modbus 시작·중지 버튼**을 배치했습니다.
- 그 아래에는 현재 읽기 대상과 통신 상태, 두 열의 읽기 전용 센서 정보 카드가 있습니다. 카드에는 채널 수·Slave ID·FC03·읽기 주기를 표시하고, 현재 대상은 테두리로 구분합니다. 아래 정보는 스크롤해서 확인합니다.
- 센서 탭으로 그래프와 읽기 대상을 전환합니다. Home 복귀 시 통신과 기록은 유지합니다. 중지하면 새 읽기를 예약하지 않고, 진행 중인 읽기의 결과는 화면에 반영하지 않습니다.
- 그래프에는 센서군 전체 채널을 겹쳐 표시하고, 아래 두 열 카드에 채널별 현재값을 표시합니다. 높이는 `LV_DPX(220)`에서 `LV_DPX(176)`으로 20% 줄였습니다.
- 오른쪽 위 작은 범례형 툴팁 하나에 부위별 첫 채널의 변환값을 한 줄씩 표시합니다. 선 색상에 맞추고 소수 둘째 자리까지 표시하며, 단위는 그래프 제목을 따릅니다. 수신 전·실패 시에는 `--`입니다.

| 센서군 | 툴팁 대표 채널 |
|---|---|
| LWTM | PS_Cyl1 / Exh_Cyl1 |
| BTM | CrkP_Cyl1 / MB_Fore |
| B-WACS | CYL1_Wear_FS / CYL1_Wear_AS (현재 시리얼 제외) |
| O-WACS | Water Activity |
| AVM | AVM |

- 페이지 오른쪽에 별도의 넓은 여백을 두지 않고 컴포넌트 폭을 줄여 스크롤할 공간을 확보했습니다.
- 차트 하나를 선택 탭으로 이동해 재사용합니다. 다른 센서 탭으로 전환하면 그래프 이력은 초기화하고, 이전 요청의 늦은 응답은 요청 ID와 설정 세대로 걸러냅니다.
- LVGL 메모리는 32KB에서 64KB로 확장했습니다.

### 보드레이트

- 기본값 9600, 선택 옵션은 **9600 / 19200 / 38400 / 57600 / 115200 / 230400 / 460800 / 921600**입니다.
- 선택 속도를 전체 읽기 작업에 저장하고 UART 작업이 시작 전에 적용합니다. 진행 중인 읽기는 기존 속도로 마무리하고 다음 읽기부터 새 속도를 사용합니다.
- UART 속도 설정 실패 시 전송하지 않고 실패 결과와 읽기 완료를 통지합니다.
- 설정은 재부팅하면 9600으로 초기화됩니다. 상대 장치와 동일한 속도를 사용해야 합니다.

## 3. 채널 매핑과 읽기 묶음

기능코드 선택 UI를 제거하고 센서 읽기를 FC03으로 고정했습니다.
Device Address는 제공된 표의 10진수 값을 그대로 요청 주소로 사용합니다. 앞자리를 제거하거나 1을 빼지 않습니다.

| 센서군 | 채널 수 | Slave ID | 연속 주소 묶음 | 현재 시리얼 읽기 |
|---|---:|---:|---|---|
| LWTM | 10 | 2 | 11083~11092: 10개 | 사용 |
| BTM | 12 | 2 | 11003~11008: 6개 / 11011~11015: 5개 / 11321: 1개 | 사용 |
| B-WACS | 10 | 0 | 10004~10013: 10개 | 제외 |
| O-WACS | 1 | 1 | 20: 1개 | 사용 |
| AVM | 1 | 2 | 11129: 1개 | 사용 |

- 읽기 대상은 **현재 선택한 센서군의 전체 채널**입니다. 모든 센서군을 동시에 읽는 방식은 아닙니다.
- B-WACS 매핑과 그래프·범위 설정은 보존하되, 현재 시리얼 출력 대상에서 제외됐다는 요청에 따라 읽기 및 시작 버튼을 비활성화했습니다.
- B-WACS의 Fore/After 순서처럼 화면 순서와 주소 순서가 다른 경우에도 응답 주소를 기준으로 정확한 채널에 배분합니다.
- BTM의 미지정 주소 11009·11010을 임의로 읽지 않으므로 묶음은 3개입니다.

## 4. 500ms 주기 및 수신 성능 개선

- 500ms는 개별 요청의 대기 시간이 아니라 **전체 읽기 시작 간격**입니다.
- 첫 시작은 즉시 예약합니다. 일찍 완료되면 직전 시작 시점으로부터 500ms가 될 때까지 기다립니다.
- 이전 전체 읽기가 끝나기 전에는 다음 읽기를 예약하지 않습니다. 500ms를 넘겼으면 완료 후 다음 읽기를 시작하며, 밀린 주기를 여러 번 실행하지 않습니다.
- UI의 예약 확인 주기는 10ms입니다. 실제 UART 시작 시점에는 태스크 스케줄링 및 RTU 프레임 간격에 따른 지연이 있을 수 있습니다.
- 한 바퀴를 하나의 작업으로 원자적으로 큐에 넣습니다. UART 작업이 각 응답 처리 후 RTU 무통신 간격을 지키고 다음 주소 묶음을 직접 요청하므로, 묶음 사이에 UI 타이머를 기다리지 않습니다.
- 요청마다 UART 버퍼 전체 256바이트를 기다리던 수신을 실제 응답 길이 기반 수신으로 변경했습니다.
- 헤더/데이터 분할 수신, 요청 에코, Modbus 예외, CRC 오류를 처리합니다. 묶음 하나가 실패해도 실패 결과를 전달하고 다음 묶음으로 진행합니다.
- 응답 제한 시간은 묶음당 300ms입니다. 마지막 묶음의 실패도 완료로 통지합니다. UI가 자체 타이머로 완료를 추정하지 않습니다.
- 모든 묶음 처리가 끝난 뒤 숫자와 그래프를 한꺼번에 갱신합니다. 실패한 채널은 `응답 없음`과 그래프의 끊어진 구간으로 표시합니다.
- 통신 속도는 기본 9600 baud이며 Home에서 변경할 수 있습니다. 실제 장비가 시간 내 응답하는 경우에 500ms 주기로 갱신되며, 타임아웃이 발생하면 한 바퀴가 500ms를 초과할 수 있습니다.

## 5. 단위 변환과 표시 범위

`표시값 = raw × Scale + Offset`

현재 모든 Offset은 0입니다. 현재값과 그래프 좌표에 같은 변환 함수를 사용하며, 숫자는 소수 둘째 자리까지 출력합니다.

| 센서군 | Scale | Offset | 센서 최소 | 센서 최대 | 단위 |
|---|---:|---:|---:|---:|---|
| LWTM | 0.1 | 0 | 0 | 300 | °C |
| BTM | 0.1 | 0 | 0 | 200 | °C |
| B-WACS | 1 | 0 | 1000 | 7000 | µm |
| O-WACS | 0.01 | 0 | 0 | 1 | A<sub>w</sub> |
| AVM | 0.01 | 0 | 0 | 20 | mm |

- 그래프 Y축은 센서 범위로 고정합니다. 범위를 벗어난 값은 차트 경계에 표시하지만 현재값 자체는 자르지 않습니다.
- 마지막 요청에 따라 **알람 기능을 제거**했습니다. 알람 판정, 상·하한 설정, 문구, 강조 테두리, 기준 표시 및 CSV 알람 열은 최종 코드에 없습니다. 그래프와 현재값만 표시합니다.
- 예: O-WACS raw 19 → 0.19 A<sub>w</sub>, BTM/LWTM raw 723 → 72.30°C, AVM raw 576 → 5.76mm.
- BTM/LWTM의 통신 분해능은 0.1°C이므로, 소수 둘째 자리 표시는 원래 전송값보다 정밀한 측정값을 복원하는 것이 아닙니다.

## 6. 폰트

- 기본 영문·숫자·영문 키보드 문자는 기존 LVGL Montserrat 16을 사용합니다. 탭·툴팁·Home 카드 상세 정보에는 Montserrat 12를 사용하도록 설정했습니다.
- 한글은 Galmuri를 사용합니다. 하나의 문장 안에서도 글자에 따라 폰트를 선택합니다.
- 혼합 폰트를 애플리케이션 테마에 적용해 새로 만드는 키보드·입력창에도 상속되도록 했습니다. 현재 화면에는 별도 키보드 입력창이 없습니다.
- °C / µm 기호를 표시하고, O-WACS 값 표시의 w는 작게 내려 A의 아래 첨자처럼 보이도록 처리합니다. CSV에는 일반 텍스트 `Aw`로 기록합니다.

## 7. 검증

```sh
python3 tests/run_sensor_ui.py
python3 tests/run_modbus_transport.py
```

- UI 호스트 테스트: 실제 저장소의 LVGL 소스를 컴파일해 실행합니다. 500ms 시작 간격, 주기 초과 시 중복 금지, 연속 주소 묶음, 일괄 표시, 실패·늦은 응답, 단위 환산, 고정 범위, 영문/한글 폰트 선택, 센서군 100회 전환, Home 복귀 시 통신 유지, 대표값 툴팁, 보드레이트의 다음 읽기 적용을 검증했습니다.
- 통신 호스트 테스트: 실제 통신 소스의 프레임 생성·파싱·수신·묶음 처리 코드를 사용하고 UART/FreeRTOS만 모의 처리합니다. 분할 응답, 요청 에코, CRC 오류, 예외, 타임아웃, 실패 후 다음 묶음 진행, 큐 등록, 보드레이트 적용, 잘못된 속도 거부, UART 속도 설정 실패 시 전송 방지를 검증했습니다.
- 320×240 호스트 렌더링으로 6개 탭, Home의 콤보박스·시작/중지 배치, 두 열 정보 카드, 그래프·툴팁, 폰트와 단위 표시를 확인했습니다.
- **ESP-IDF 펌웨어 전체 빌드와 실제 장비 통신·화면 동작은 확인하지 못했습니다.** 설치된 Windows ESP-IDF 4.4.3 도구를 WSL에서 실행할 때 `UtilBindVsockAnyPort: socket failed 1` 오류가 발생했습니다. 호스트 테스트 성공을 펌웨어 빌드 성공으로 간주하지 않습니다.
- 기존 `build` 캐시는 다른 프로젝트 경로를 포함하므로 Windows ESP-IDF 터미널에서 아래처럼 별도 폴더로 빌드해야 합니다.

```sh
idf.py -B build_modbus_src build
```

## 8. 작업 중 변경된 방향

- 초반에는 Home을 없애고 EDPD / 그래프 두 탭으로 구성했으며, 센서 선택 버튼 높이를 줄였습니다. 이후 요청에 따라 선택 버튼을 제거하고 **현재의 Home + 센서별 탭**으로 개편했습니다.
- 알람 기준과 표시를 추가했다가 최종 요청에 따라 제거했습니다. 현재는 그래프와 값만 표시합니다.
- 툴팁은 채널별 여러 상자 대신 **대표값을 모은 작은 상자 하나**로 정리했습니다.
- README를 기존 데모 소개에서 현재 프로그램의 사용법·통신 방식·설정·검증 안내로 교체했습니다. 채널 설정 목록은 [ModbusTable.csv](ModbusTable.csv)에 유지합니다.
